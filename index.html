About Paran OS

Paran OS is a fully open-source operating system built from scratch on the Linux kernel. It is designed with customization and security in mind, giving users complete control over their system.

  • Built on the Linux Kernel
  • Fully Open Source
  • Build from Scratch Capability
  • Highly Customisable
  • Security Enforcement
